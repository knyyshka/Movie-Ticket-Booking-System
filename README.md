# 🎬 Movie Ticket Booking System
//UML(Class Diagram) & Sequence Diagram is atttached

## Overview
A console-based Movie Ticket Booking System developed in **C++** using **Object-Oriented Programming (OOP)** concepts. The project allows users to view movies, select shows, book seats, make payments, generate tickets, and cancel bookings.

## Features
- View available movies and shows
- Display seat availability
- Book one or multiple seats
- Calculate ticket price automatically
- Pay using UPI, Card, or Cash
- Generate booking ticket
- Cancel bookings and release seats

## OOP Concepts Used
- Encapsulation
- Abstraction
- Inheritance
- Runtime Polymorphism
- Compile-Time Polymorphism
- Composition
- Aggregation
- Association
